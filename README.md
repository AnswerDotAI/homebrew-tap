# AnswerDotAI Homebrew Tap

Install `fbz` directly:

```bash
brew install AnswerDotAI/tap/fbz
```

Or add the tap first:

```bash
brew tap AnswerDotAI/tap
brew install fbz
```

In a `Brewfile`:

```ruby
tap "AnswerDotAI/tap"
brew "fbz"
```

See [fbz](https://github.com/AnswerDotAI/fbz) for usage and documentation.
